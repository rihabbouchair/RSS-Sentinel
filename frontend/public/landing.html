// core features

Everything you need to read smarter

📡
RSS Aggregation
Pull the latest headlines from any RSS source automatically. FeedParser handles dozens of formats so you can focus on reading, not configuring.
🧠
Local AI Analysis
Ollama + Qwen 2.5:3b runs fully on your machine. Zero API calls, zero subscription fees, zero data leaving your device.
📊
Sentiment Scoring
Every article receives a Positive, Neutral, or Negative score. Filter your feed by emotional register and track global mood trends.
⚡
Real-time Dashboard
A sleek React + Tailwind interface that updates live. Topics sidebar, sentiment filters, and AI-generated daily summaries built in.
📧
Email Digests
Subscribe to curated topic digests delivered to your inbox. Configure frequency and preferred topics in the settings panel.
🔒
Privacy-First
All processing happens locally. SQLite stores your data on disk. No external inference, no cloud lock-in
// how it works

Four steps from feed to insight

01
Fetch
FeedParser polls your RSS sources on a configurable schedule, pulling fresh articles as they're published.
02
Filter
A keyword pre-filter and topic classifier routes each article to one of 50+ topics .
03
Analyze
Ollama runs Qwen 2.5:3b locally to score sentiment, extract key themes, and generate a concise summary per article.
04
Visualize
Results are stored in SQLite and surfaced instantly in the React dashboard with filters, charts, and daily briefings.

Start reading smarter

Clone the repo, install dependencies, and launch NewsPulse locally. No cloud setup, no API keys.

# 1. Pull the model
ollama run qwen2.5:3b:

# 2. Start the backend
cd backend && pip install -r requirements.txt
uvicorn main:app --reload

# 3. Start the frontend
cd frontend && npm install && npm run dev
